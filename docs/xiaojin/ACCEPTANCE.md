# 小金账人工验收清单

## Board 01

1. 首次启动 → 创建空间 → 设置并确认 6 位密码 → 空账本列表 → 创建账本 → 首页。
2. 创建第二账本，切换、设默认；退出重进默认账本。
3. 我的 → 安全与隐私 → 创建独立空间，使用不同密码。普通空间中不出现该空间的账本、记录、数量或主题。
4. 输入错误密码验证提示，连续 5 次错误锁定 5 分钟；锁屏不显示空间列表。
5. 复制账本的三种范围、归档后只读、恢复归档、两步删除与完整名称确认。
6. 后台切换回来时立即锁屏；Android 最近任务和截屏保护需真机检查。

## 记账与扩展字段

1. 支出、收入、两个不同账户间转账；转账不得增加首页收支。
2. 空金额、过多小数、缺分类、条件必填失败；保存草稿、继续记账、复制、编辑、删除后撤销。
3. 自定义字段 → 条件显示 → 必填；隐藏条件不能阻止保存，历史值不能丢失。
4. 字段改名、停用、删除以及移除选项后查看历史记录；已有值的字段不能更换类型。
5. 图片/文件在取消选择、权限拒绝、超过 1 MB 时正确提示；锁屏后的异步回调不得重新填入敏感内容。

## 统计、恢复及适配

1. 分类环图点击明细与汇总一致；折线、柱状、排行、数字指标按相同数据源计算。
2. 自定义数字指标、空结果、负数、不同币种；统计不得跨越未解锁空间。
3. 导出加密备份 → 密码错误 / 损坏文件 → 正确校验预览 → 合并 / 覆盖 → 回滚。
4. 更改备份内容或密码必须清除旧预览；写入失败不得覆盖原存储。
5. Web 断网刷新后仍可解锁、记账；390px / 768px / 1280px 检查底栏、侧栏、表单和滚动。
6. 真机验证 Android、iOS、HarmonyOS 文件选择器生命周期。原生备份在应用目录，不等于卸载可恢复的独立备份。
