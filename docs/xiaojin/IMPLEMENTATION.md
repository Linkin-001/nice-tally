## 数据与兼容

新存储使用 xiaojin.v2 前缀，旧 nice-tally.ledger.v1 数据不自动覆盖。金额为整数分，转账不计入收支。历史记录保留停用配置与字段值。当前解锁空间是查询的唯一作用域。

密码空间采用 PBKDF2-SHA256 + AES-256-GCM，随机数来自系统密码学随机源；无随机源时拒绝创建，禁止 Math.random 降级。清除内存会话后重新验证密码。备份为当前空间的加密包；恢复先验证，再选择合并或覆盖；覆盖前保留加密快照。

## 平台边界与后续验收

- 生物识别、恢复密钥暂未实现，界面明确说明，未使用模拟成功代替原生验证。
- Android 安全窗口由原生插件设置。iOS/HarmonyOS 最近任务遮挡尚未实现；两端安全随机数适配代码未经过本机跨平台编译/真机验证。
- Web 支持本地附件选择、图片预览、文件下载，以及加密备份下载/导入。原生端已接入 uni.chooseFile 与文件系统读写，需要真机验证系统文件选择器的生命周期与权限。单附件限 1 MB、导入备份限 20 MB。
- 原生备份文件目前写入应用数据目录；卸载应用会删除该目录，不能视为独立灾备。界面提示另行保存加密内容。原生文件附件向其他应用导出尚未开放，避免产生无人管理的明文副本。
- 6 位 PIN 按原型实现；PBKDF2-SHA256（210,000 次）+ AES-GCM 不会消除短密码遭离线穷举的风险。未实现 Keychain/Keystore 硬件密钥封装。上线前需要安全审查，不能宣称抵御设备取证。
- 空间隔离针对应用页面、查询和加密访问；本地密文容器的槽位数量和密文大小并未做填充隐藏。
- 字段按账本配置；复制账本可复用配置，尚无跨账本共享字段模板。对象引用目前保留选择时的名称值。高级多条件布尔规则、动态字段的任意 BI 筛选组合、汇率折算尚未实现。
- 列表采用点击和长按操作；左滑操作、原生分享、桌面原生安装包尚未实现。业务页面已提供空态、失败、强确认及删除记录的 5 秒撤销。

## 既有编译错误

`_decoded`：5.24 的 CSS 插件在外部 CSS 产生 warning 后，未经检查向 source-map 函数传入 undefined。本次通过临时内联样式看到真实告警：max-height 不支持百分比。改为像素值后恢复外部样式并编译成功。不是 tally.css 第 1 行本身语法错误，不应盲删样式。

`EPERM rename cache_ → cache`：属于生成缓存路径占用，和业务逻辑分开处理。本次使用 HBuilderX 官方 cleanCache 编译参数成功恢复，没有删除用户源文件或关闭系统安全软件。

原生文件 API 依据官方接口接入：[chooseFile](https://doc.dcloud.net.cn/uni-app-x/api/choose-file.html)、[FileSystemManager](https://doc.dcloud.net.cn/uni-app-x/api/get-file-system-manager.html)。
